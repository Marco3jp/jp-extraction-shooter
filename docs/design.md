# ゲーム内容

## 決まっていること

### 遊び方
- オフラインのソロプレイ。いつでもポーズできる
- 気軽に始められて、始まったら集中して遊ぶ
- 1ランは5〜10分（7分前後）が基本。周回なら数分、漁りを長くする攻略なら15分ほど
- 脱出シューター。死んでも失うものはほとんどない
- ポーズ画面からリタイアできる。死んだときと同じ扱いになる

### 視点と操作
- 斜め見下ろし（LoL のような視点）
- メインは PC。カーソルの方向へ正確に撃つ。武器ごとのブレ・拡散は別にある
- スマホでの操作は後で考える
- 立体構造（建物の2階・屋上・高低差）は入れない
- 普段の移動に加えて走れる（Shift）。撃つと走るのをやめる
- スペースキーで短距離ダッシュ。のぞき込み・移動・撃ち合いの最中に使う。クールダウンは5秒くらいで、使うと巻きは止まる
- ダッシュは今は一方向だけ。後でスケートのように左右に振れる動きを入れることも考える
- 持ち物の画面、ミニマップ、全体マップがある。持ち物の画面を開いている間は撃てないが、画面の外では照準を出したままにする
- 拾う・箱を開けるは E キー

### 戦闘
- TTK は理論値で、敵は最短1.5秒、プレイヤーは最短0.75秒。弾除けなどで実際はもっと長くなる
- 1マガジンで倒しきるのは、うまくプレイしたときだけにする。リロード時に引いて巻くか、サブウェポンに持ち替えてでも倒しきるかを選ばせる
- 相手のリロード・巻き・シールド割れなどは、エフェクトと効果音で分かるようにする
- 当てたダメージは、相手ごとに積み上げて頭の横に出す（18 → 36 → 54）。最後に当ててから1.5秒で消え、次は0から数え直す。センサーで見えていない相手には出さない
- 巻きの所要時間（案）
  - シールド1個：2秒。4個まとめて：5秒
  - ヘルス小：3.5秒。ヘルス大：8秒
- 巻きながら移動できるが、速くは走れない
- 被弾しても巻きは止まらない。自分でキャンセルできる
- まとめ巻きを途中でやめたら、何も回復しない

### 情報の見え方
- センサー技術の物語として、視界の情報を多めに出す
- 敵の影が見える。影から敵の型（近距離・中距離・遠距離）や体力の量が分かるかどうかを、センサーの強さで変える
- 音の左右で敵を探す作りにはしない
- 強化していくもの：ビーコンの範囲、センサーモジュールの設置、無線の性能による設置数
- 建物の裏に隠れて画面では見えなくても、視線が通っている人は輪郭を重ねて出す
- 画面に映っていない所の銃声は、その方向の画面の端に波で出す。近いほど濃く大きい。タレットの銃声は色を分ける。効果音は方向を付けず、遠いほど小さくこもらせる
- 設置物（センサー・タレット）は拠点で作って持ち込み、ラン中に足元に置く。置いた物はマップに残り、次のランでも同じ所にある。周回するルートの安全を自分で作るための道具
  - マップに置ける数に上限がある（試作ではセンサー4・タレット2）。E で回収すると持ち物に戻る
  - プレイヤーから離れた物は止まる（試作では 200m）
  - センサーは、範囲の敵の型を壁越しに見せる。タレットは近くの敵を撃ち、敵にも狙われて、壊されたらなくなる

### 武器
5種類。武器と弾薬は1対1で対応する。

| 武器 | 役割 |
|---|---|
| アサルトライフル | 安定して使える |
| サブマシンガン | 火力が高く、反動が強い。弾薬のスタック数が少なく、カバンを圧迫する |
| 遠距離武器 | 遠くから戦いたい人向け。効率より好みで選ぶ |
| ショットガン | 突っ込んで戦う |
| ピストル | 弾薬がカバン1枠で足りる。難しいエリアでは力不足なので、楽なエリアでの周回向け |

### 投げ物
- グレネード：投げてから少しして爆発し、周りにダメージ
- テルミット：落ちた場所から、投げた向きと直角に横へ燃え広がる。炎の中では足が大きく遅くなり、出てからも少しの間は遅いまま。遮蔽の裏に投げ込んで、撃たれに出るか焼かれ続けるかを選ばせる道具で、炎からすぐ出れば受けるダメージは小さい
- キーを押している間に落ちる場所を確かめ、離すと投げる

### アタッチメント
武器は種類ごとに1つだけで、アタッチメントで性能の傾向を変える。作り込みの重心はアタッチメントのクラフトに置く。

- 遠距離武器：連射とマガジン量に寄せるとマークスマンライフル、単発の火力に寄せるとスナイパーライフルになる
- サブマシンガン：火力を上げて反動を大きくすると、制御しづらいが攻撃的になる（Apex の R-99 のような武器）
- アタッチメントは、集めた素材からクラフトする

### 漁り
- Apex と同じくらいの量を落とす。1つの箱に4個入っていて、箱が4つ並ぶ場所もある
- 箱のほかに、地面にもそのまま落ちている
- 倒した相手は持ち物を落とす

### 持ち込み・持ち帰り
- 持ち込む装備（武器・アタッチメント・防具・カバン・靴・自転車、センサーなどの道具）は、集めた素材からクラフトする
- 靴は移動速度だけを上げる。下がる性能はない
- 素材は上位素材にクラフトできる
- ラン中に拾うもの：弾薬・回復アイテム・グレネード・素材・お金・アルティメット加速・バフアイテム・蘇生アイテム・長距離移動アイテム
- バフアイテム（強化パーツ）は、拾った時点からそのランの間ずっと効く。薬のような一時的なものではなく、シールドやアタッチメントの類で、装備が1つ増えたのと同じになる
- 消耗品は毎回持ち帰らない
- 特定の装備で特定の時間に特定の場所へ行かないと手に入らない仕組みは作らない。普段のプレイでのレアドロップは入れる
- 消えるもの：消耗品、ラン中のバフ、パートナーのラン中の装備
- かなりのレアとして、蘇生アイテム（持ち帰れる。死んだらその場で立ち上がる）と長距離移動アイテム（全体マップで選んだ所へ飛んでいく）を置く
- 特殊カバンを持ち込むと、死んでも持ち帰れる枠が付く
- それ以外は負けても消えない

### ビルド
- スキル・パッシブを装備してプレイスタイルを作る。ユニークスキル・パッシブのセットに、一般スキルを組み合わせる
- スキルの例：一時的なシールド、視界の拡張、ビーコントラップから派生したタレット
- 誰かのキャラクターを演じるのではなく、プレイヤー自身がそうなる
- パートナー（ペット・オトモにあたるもの）がいる

### 敵
- 基本は人間。人間がドローンやロボットを使う
- 存在の理由がつかない敵は出さない。何も守らず、持ち主もいないドローンなど
- グループで動く敵が多く、ソロの敵もそこそこいる
- 敵どうしも撃ち合う。銃声を聞いた敵は寄ってくるので、撃ち合いに別の勢力が割って入る。タレットに撃ち合いを起こさせて、寄ってきた勢力どうしが削り合った所を取ることもできる

### マップ
- 東京都か神奈川県の、住宅街に近い市街地がベース
- 試作の地域は、秋葉原の電気街から神田・日本橋を通って東京駅まで
- OpenStreetMap の地図をデフォルメして組む。正確さは求めない
- 細かい地面の模様や、1m単位の建物の凹凸は描かない
- マップ全体を同じ倍率（今は 0.8 倍）で縮める。道は縮めずに、道の種類ごとに決めた幅で描く
- 将来は日本全体を遊べる規模にしたい。各街を正確に再現するのではなく、特徴的な場所を中心に作る
- 出発地点・脱出地点は、マップごとに決める。勢力の縄張りは町ごとで、ランが変わっても同じ
- 脱出地点はマップに複数あり、どこからでも出られる。脱出地点で E キーを押して迎えを呼ぶと、迎えが来るまでの防衛になる
  - 脱出地点の周りに壁が立ち、勢力の違う敵のグループが別々の方向から寄ってくる。着いた勢力どうしも撃ち合うので、籠城しながら、ぶつかり合っている所を崩していける
  - 脱出地点の円の中にいる間、カバンのお金・素材・蘇生アイテムが少しずつ送られ、60% まで送れる。送った分は死んでも持ち帰れる。円の外に出ている間は止まる
  - 迎えが来てから中に少しいれば脱出して、残りも持ち帰る
- 脱出した後、その脱出地点の近くにキャンプを置ける。次のランはキャンプから始まる。キャンプは拠点の出撃準備でたためる
- 広いマップを移動しやすくする設備を、マップの整合性を崩さない形で道に置く。大通りには固定レール（端から乗ると反対の端まで速く進み、乗り継げる）、細い道にはダッシュパッド（踏むと 30m 飛ぶ）。どちらも進む間に撃てる。固定レールは逃げるのにも使えるので、乗るたびに維持費として金属くずを払う
- 自転車は持ち込む装備で、乗っている間は速いが撃てない。撃とうとするか撃たれると降りる

#### 建物の種類

#### 地面と地名
- 地面には、大きな道の交差点の横断歩道、太い道の中央線、細い道から太い道へ出る所の停止線と「止まれ」、マンホールを描く
- 通りの名前は、交差点の角に青い案内標識で出す。駅には駅名標を立てる
- 町名が変わる所に入ったら、戦闘中でなければ画面の上に「〜エリア」と出す
- 店やビルの名前は出さない。実在の会社の名前になるため

### 世界観
- 若者を中心とした社会不信で、世紀末のようになった現代の日本
- 主人公はハードウェアもソフトウェアも作れる。日々を送りながらどうにか生きていく
- キャンプを解禁して各地を転々としつつ、たまに拠点へ戻る

## 決めること

### 名前
- 正式な名前。今の `jp-extraction-shooter` は仮で、決まったらリネームする
- 名前で伝えたいこと：カジュアルな脱出シューター、日本の世紀末の世界観、センサー・スキル・武器のカスタムで個性を出せること

### 今の試作に効くもの
- 建物の中に入れるようにするか（試作では入れず、プレイヤーに重なる手前の建物を透かしている）
- カメラを回せるか、ズームできるか
- 敵の勢力と、勢力ごとの人数（グループ・ソロ）。世界観の中でなぜその人数で動いているか。試作では「勢力A」「勢力B」「単独」と仮に置いている
- 素材の種類。試作では金属くず・電子部品・精密部品と仮に置いている
- 死んだときに、ラン中に集めた素材とお金を失うか。「消耗品・ラン中のバフ・パートナーの装備以外は負けても消えない」と食い違うので決める。試作では失う（持ち込んだ装備は失わない）
- 防具の段階。試作ではシールド上限 100 / 125 / 150 で、重いほど少し遅くなる
- カバンの段階。試作では 12 / 16 / 20 枠
- 靴の段階。試作では移動速度 +0% / +6% / +12%
- 自転車の段階。試作では秒速 12m（乗るのに 0.6 秒）/ 13.5m（0.4 秒）
- ラン開始時に毎回もらう物。試作では持ち込む武器のマガジン3本分の弾薬と、シールドセル4個・ヘルス小2個
- 敵も遮蔽に隠れて巻くか、こちらの巻きに合わせて詰めてくるか。試作では両方入れている
- センサー範囲を外れた敵の最後の位置を残すか
- 建物に接した箱の中身をどれだけ寄せるか。試作では用途ごとに出やすさを2〜3.5倍にしている。箱は壁沿いに置くのでほぼ全部が建物に接していて、秋葉原では事務所と商店に接した箱が多く、電子部品と精密部品が出やすい
- リタイアを死んだときと同じ扱いにするか。試作では戦績の死亡数にも数える
- 敵の状態（リロード・巻きなど）は、センサーの強さに関係なく見えるか

### ラン
- 周回と攻略は、同じマップで目的が違うのか、別のマップなのか
- 脱出の条件：防衛の長さと、寄ってくる敵の量。試作では迎えが来るまで45秒、来てから中に2秒。呼んだ時点で 60m 以内にいた敵と、呼んでから 0・8・16 秒後に 50〜70m 先へ出す3グループが寄ってくる
- 現地でセルを補給しないと動かない代わりに、多く持ち込める設置物を入れるか
- キャンプを置ける距離と数。試作では脱出地点から250m以内に1か所。死んだときもキャンプは残る
- 時間で迫ってくるもの（Apex のリングにあたるもの）があるか
- 敵の配置は固定か、湧き直すか
- ブラウザを閉じてもラン途中から再開できるか、ポーズだけか

### 戦闘と成長
- HP を増やす成長にするか、防御力で調整するか。HP を増やすならシールド4枠の回復にするか
- 敵の強さ：数発で倒されるがセンサーで先手を取れる敵か、撃ち合える敵か。エリアごとに変えるか
- キャラクターのステータスは何で上がるか（装備・スキル・レベル）
- 持ち込める武器の本数。試作では2本
- 武器そのものに強化やレア度があるか
- 弾薬はラン中に拾うだけか、持ち込めるか。試作では毎回もらう（上の「ラン開始時に毎回もらう物」）
- カバンの形：種類ごとのスタック枠か、形のあるマス目か。試作ではスタック枠で、出し入れのたびに自動で並べ直す
- クラフトの段数と、要る素材とお金の量。最初の何回かの出撃で何が作れると気持ちいいか

### アタッチメント
- 付けられる箇所の数と種類（銃身・マガジン・ストック・スコープなど）
- 1つのアタッチメントで変わる性能の数。上がる性能と下がる性能を必ず組にするか
- アタッチメントにもレア度や段階があるか
- 付け替えは拠点だけか、ラン中もできるか。ラン中に拾えるか
- 試作では、銃身・機関部・マガジン・ストックの4か所に、どの武器にも付けられるアタッチメントを11種類置いている

### 投げ物とダッシュ
- 試作の数値：グレネードは半径5m・中心85ダメージ、テルミットは長さ最大12m・幅2m・6秒・1秒32ダメージ・炎の中と出てから0.6秒は移動速度35%、ダッシュは4.5m・クールダウン5秒
- 投げ物は自分にも当たる。敵は今は投げ物を使わない。敵にも使わせるか
- 敵はグレネードに着地から少し遅れて気づき、爆発の届かない場所か遮蔽の裏へ逃げる。炎の中に入ったら、狙っている相手から見えない側を選んで外へ出る。ただし相手が瀕死で自分に余裕があれば、炎に留まって撃ち合う。歩く道は、炎を突っ切るより回り道を選ぶ（回り道が無ければ突っ切る）

### 敵の強さの調整
敵を安定して倒せるようになったら終わり、にならないようにしたい。何を上げると強くなるかを分けて決める。

- 撃ち合い：反応の速さ、エイムの正確さ、連射の我慢
- 立ち回り：遮蔽の使い方、巻くタイミング、リロードの隙を見せないか
- 連携：挟み撃ち、仲間が巻く間の援護、狙う相手を揃えるか
- 判断：詰める・引くの見極め、横から割り込むタイミング
- 生き残り：撃ち合いに勝つより、最後まで生き残るのがうまい
- 上の項目を、エリア・敵の装備・ゲームの進み具合のどれに結び付けて上げていくか

### センサーとビルド
- ゲームを始めた時点で見えるもの、見えないもの
- 強化する項目：範囲・精度・設置数・持続時間・種類のどれを持たせるか
- 敵もプレイヤーを探知してくるか
- 設置や使用のコスト（電力・素材・クールダウン）
- ユニークスキル・パッシブのセットの数と、手に入れ方
- 一般スキルの枠の数と、後から増えるか
- パートナーの役割（戦闘・索敵・荷物持ち）と、成長するか

### ロストと持ち帰り
