# ゲーム内容

## 決まっていること

### 遊び方
- オフラインのソロプレイ。いつでもポーズできる
- 気軽に始められて、始まったら集中して遊ぶ
- 1ランは5〜10分（7分前後）が基本。周回なら数分、漁りを長くする攻略なら15分ほど
- 脱出シューター。死んでも失うものはほとんどない

### 視点と操作
- 斜め見下ろし（LoL のような視点）
- メインは PC。カーソルの方向へ正確に撃つ。武器ごとのブレ・拡散は別にある
- スマホでの操作は後で考える
- 立体構造（建物の2階・屋上・高低差）は入れない
- 普段の移動に加えて走れる（Shift）。撃つと走るのをやめる
- スペースキーで短距離ダッシュ。のぞき込み・移動・撃ち合いの最中に使う。クールダウンは5秒くらいで、使うと巻きは止まる
- ダッシュは今は一方向だけ。後でスケートのように左右に振れる動きを入れることも考える
- 持ち物の画面、ミニマップ、全体マップがある

### 戦闘
- TTK は理論値で最短1.5秒。弾除けなどで実際はもっと長くなる
- 1マガジンで倒しきるのは、うまくプレイしたときだけにする。リロード時に引いて巻くか、サブウェポンに持ち替えてでも倒しきるかを選ばせる
- 相手のリロード・巻き・シールド割れなどは、エフェクトと効果音で分かるようにする
- 巻きの所要時間（案）
  - シールド1個：2秒。4個まとめて：5秒
  - ヘルス小：3.5秒。ヘルス大：8秒
- 巻きながら移動できるが、速くは走れない
- 被弾しても巻きは止まらない。自分でキャンセルできる
- まとめ巻きを途中でやめたら、何も回復しない

### 情報の見え方
- センサー技術の物語として、視界の情報を多めに出す
- 敵の影が見える。影から近距離型か遠距離型か、体力の量が分かるかどうかを、センサーの強さで変える
- 音の左右で敵を探す作りにはしない
- 強化していくもの：ビーコンの範囲、センサーモジュールの設置、無線の性能による設置数

### 武器
5種類。武器と弾薬は1対1で対応する。

| 武器 | 役割 |
|---|---|
| アサルトライフル | 安定して使える |
| サブマシンガン | 火力が高い。弾薬のスタック数が少なく、カバンを圧迫する |
| 遠距離武器 | 遠くから戦いたい人向け。効率より好みで選ぶ |
| ショットガン | 突っ込んで戦う |
| ピストル | 弾薬がカバン1枠で足りる。難しいエリアでは力不足なので、楽なエリアでの周回向け |

### 投げ物
- グレネード：投げてから少しして爆発し、周りにダメージ
- テルミット：落ちた場所から、投げた向きと直角に横へ燃え広がる
- キーを押している間に落ちる場所を確かめ、離すと投げる

### アタッチメント
武器は種類ごとに1つだけで、アタッチメントで性能の傾向を変える。作り込みの重心はアタッチメントのクラフトに置く。

- 遠距離武器：連射とマガジン量に寄せるとマークスマンライフル、単発の火力に寄せるとスナイパーライフルになる
- サブマシンガン：火力を上げて反動を大きくすると、制御しづらいが攻撃的になる（Apex の R-99 のような武器）
- アタッチメントは、集めた素材からクラフトする

### 漁り
- Apex と同じくらいの量を落とす。1つの箱に4個入っていて、箱が4つ並ぶ場所もある
- 箱のほかに、地面にもそのまま落ちている
- 倒した相手は持ち物を落とす

### 持ち込み・持ち帰り
- 持ち込む装備（武器・アタッチメント・防具・カバン・靴、センサーなどの道具）は、集めた素材からクラフトする
- 靴は移動速度だけを上げる。下がる性能はない
- 素材は上位素材にクラフトできる
- ラン中に拾うもの：弾薬・回復アイテム・グレネード・素材・お金・アルティメット加速・バフアイテム
- バフアイテムはそのランの間ずっと効く
- 消耗品は毎回持ち帰らない
- 特定の装備で特定の時間に特定の場所へ行かないと手に入らない仕組みは作らない。普段のプレイでのレアドロップは入れる
- 消えるもの：消耗品、ラン中のバフ、パートナーのラン中の装備
- かなりのレアとして、蘇生アイテム（持ち帰れる）と長距離移動アイテムを置く
- それ以外は負けても消えない

### ビルド
- スキル・パッシブを装備してプレイスタイルを作る。ユニークスキル・パッシブのセットに、一般スキルを組み合わせる
- スキルの例：一時的なシールド、視界の拡張、ビーコントラップから派生したタレット
- 誰かのキャラクターを演じるのではなく、プレイヤー自身がそうなる
- パートナー（ペット・オトモにあたるもの）がいる

### 敵
- 基本は人間。人間がドローンやロボットを使う
- 存在の理由がつかない敵は出さない。何も守らず、持ち主もいないドローンなど
- グループで動く敵が多く、ソロの敵もそこそこいる
- 敵どうしも撃ち合う。銃声を聞いた敵は寄ってくる

### マップ
- 東京都か神奈川県の、住宅街に近い市街地がベース
- OpenStreetMap の地図をデフォルメして組む。正確さは求めない
- 細かい地面の模様や、1m単位の建物の凹凸は描かない
- 特徴的な場所（大通り・駅・公園・大きな建物）は縦横の比率を保って丁寧に作る。似た街並みが続くところは切り詰めて、移動を短くする
- 将来は日本全体を遊べる規模にしたい。各街を正確に再現するのではなく、特徴的な場所を中心に作る

### 世界観
- 若者を中心とした社会不信で、世紀末のようになった現代の日本
- 主人公はハードウェアもソフトウェアも作れる。日々を送りながらどうにか生きていく
- キャンプを解禁して各地を転々としつつ、たまに拠点へ戻る

## 決めること

### 今の試作に効くもの
- 建物の中にいるとき、屋根や手前の壁をどう見せるか（消す・透かす）
- カメラを回せるか、ズームできるか
- 敵の勢力と、勢力ごとの人数（グループ・ソロ）。世界観の中でなぜその人数で動いているか。試作では「勢力A」「勢力B」「単独」と仮に置いている
- 素材の種類。試作では金属くず・電子部品・精密部品と仮に置いている
- 死んだときに、ラン中に集めた素材とお金を失うか。試作では失う（持ち込んだ装備は失わない）
- 防具の段階。試作ではシールド上限 100 / 125 / 150 で、重いほど少し遅くなる
- カバンの段階。試作では 12 / 16 / 20 枠
- 靴の段階。試作では移動速度 +0% / +6% / +12%
- ラン開始時に毎回もらう物。試作では持ち込む武器のマガジン3本分の弾薬と、シールドセル4個・ヘルス小2個
- 敵も遮蔽に隠れて巻くか、こちらの巻きに合わせて詰めてくるか
- センサー範囲を外れた敵の最後の位置を残すか
- 敵の状態（リロード・巻きなど）は、センサーの強さに関係なく見えるか

### ラン
- 周回と攻略は、同じマップで目的が違うのか、別のマップなのか
- 脱出の条件：脱出地点の数、呼んでから待つ時間
- 時間で迫ってくるもの（Apex のリングにあたるもの）があるか
- 敵の配置は固定か、湧き直すか
- ブラウザを閉じてもラン途中から再開できるか、ポーズだけか

### 戦闘と成長
- HP を増やす成長にするか、防御力で調整するか。HP を増やすならシールド4枠の回復にするか
- 敵の強さ：数発で倒されるがセンサーで先手を取れる敵か、撃ち合える敵か。エリアごとに変えるか
- キャラクターのステータスは何で上がるか（装備・スキル・レベル）
- 持ち込める武器の本数
- 武器そのものに強化やレア度があるか
- 弾薬はラン中に拾うだけか、持ち込めるか
- カバンの形：種類ごとのスタック枠か、形のあるマス目か。試作ではスタック枠12個

### アタッチメント
- 付けられる箇所の数と種類（銃身・マガジン・ストック・スコープなど）
- 1つのアタッチメントで変わる性能の数。上がる性能と下がる性能を必ず組にするか
- アタッチメントにもレア度や段階があるか
- 付け替えは拠点だけか、ラン中もできるか。ラン中に拾えるか
- 試作では、銃身・機関部・マガジン・ストックの4か所に、どの武器にも付けられるアタッチメントを11種類置いている

### 投げ物とダッシュ
- 試作の数値：グレネードは半径5m・中心85ダメージ、テルミットは長さ最大12m・6秒・1秒32ダメージ、ダッシュは4.5m・クールダウン5秒
- 投げ物は自分にも当たる。敵は今は投げ物を使わない。敵にも使わせるか

### 敵の強さの調整
敵を安定して倒せるようになったら終わり、にならないようにしたい。何を上げると強くなるかを分けて決める。

- 撃ち合い：反応の速さ、エイムの正確さ、連射の我慢
- 立ち回り：遮蔽の使い方、巻くタイミング、リロードの隙を見せないか
- 連携：挟み撃ち、仲間が巻く間の援護、狙う相手を揃えるか
- 判断：詰める・引くの見極め、横から割り込むタイミング
- 生き残り：撃ち合いに勝つより、最後まで生き残るのがうまい
- 上の項目を、エリア・敵の装備・ゲームの進み具合のどれに結び付けて上げていくか

### センサーとビルド
- ゲームを始めた時点で見えるもの、見えないもの
- 強化する項目：範囲・精度・設置数・持続時間・種類のどれを持たせるか
- 敵もプレイヤーを探知してくるか
- 設置や使用のコスト（電力・素材・クールダウン）
- ユニークスキル・パッシブのセットの数と、手に入れ方
- 一般スキルの枠の数と、後から増えるか
- パートナーの役割（戦闘・索敵・荷物持ち）と、成長するか
- クラフトの段数

### ロストと持ち帰り
- 脱出したとき、持ち帰らない消耗品はどうなるか（換金するか、消えるか）
- 蘇生アイテムの効果：その場で復活するのか、持ち物を守るのか
- 長距離移動アイテムの効果：マップ内を移動するのか、その場で脱出するのか

### マップと拠点
- マップは手作りか、自動生成か、手作りの部品の組み合わせか。試作は OpenStreetMap から自動で変換し、切り詰めている
- 長距離の移動を楽にする仕組み：マップの整合性を崩さずに置けるダッシュパッド、自転車・バイク・車のような長距離移動の装備
- 切り詰めたぶん敵と箱の密度が上がっている（試作では面積が3分の2、数はそのまま）。広さあたりの数で決めるか
- エリアの難易度の分け方と、解禁の条件
- キャンプでできること（クラフト・保管・休息）と、拠点との違い
- 拠点を移ると何が変わるか（行けるマップ・敵・素材）

### 物語と見た目
- 物語の見せ方：会話シーン・拠点でのイベント・ラン中の無線・テキスト
- センサーの強化と物語の進み具合を連動させるか
- 見た目の方向（ローポリ・トゥーン・写実寄り）と、素材を作るか借りるか
