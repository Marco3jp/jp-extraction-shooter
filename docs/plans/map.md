# マップの大改修の計画

マップを広げ、どの脱出地点からでも出られるようにし、脱出した場所の近くにキャンプを置いて次のランをそこから始められるようにする。広くなったぶん、移動手段を足す。マップは区・市・県の単位まで後から足していける作りにし、遠くの区画を読み込んだり捨てたりしても、プレイヤーにロードを感じさせない。

今の作りの詳しいことは `docs/tech.md` の「マップ」と「敵と箱の置き方」にある。

## 遊び方の変化

- マップは地続きの広い1枚。1回のランで回るのはその一部で、ランの長さは今と同じ7分前後
- ランはキャンプ（最初は決まった出発地点）から始まる
- 脱出地点はマップの各地に常に複数あり、どこから出てもよい
- 脱出すると、その脱出地点の近くにキャンプを置ける。次のランはそこから始まる
- 脱出地点の近くでしかキャンプを置けないので、置けない場所が出る。今は受け入れ、後で考える
- 東京から大阪のような遠い移動は、地続きのマップの上では歩かせない。新幹線や飛行機のカットインを見せている間に、行き先の地方を読み込む

## 1. 脱出地点とキャンプ（済）

数値は仮。

- 脱出地点で E を押すと迎えを呼べる。20秒で迎えが来て、来てから中に2秒いれば脱出。呼ぶと 60m 以内の敵が呼んだ人を狙って寄ってくる
- 脱出した後の拠点の画面で、脱出地点から 150m 以内の歩ける所をクリックしてキャンプを置く。キャンプは1か所で、死んでも残る。出撃準備の画面でたためる
- キャンプはマップの id とゲームの座標で保存する
- 変換で閉じた空き地を埋めてあるので、空いているマスはどれもつながっている。キャンプをどこに置いても、マップのどこへでも行ける
- 脱出地点は変換のときに置く。駅前・公園・大きな交差点のうち開けた場所から、町ごとに1〜2か所、互いに 180m 以上離して選ぶ。秋葉原から東京駅までで 47 か所、どこにいても一番近い脱出地点まで半分の場所で 106m 以内・一番遠くて 357m

## 2. 縮め方（済）

マップ全体を 0.8 倍に縮める（仮）。どの地点も、自分の実際の緯度・経度だけでゲームの座標が決まる。範囲を後から足しても、作り済みの場所は1マスも動かない。

- ゲームの座標の原点は、関東全体で1か所（北緯37度・東経138.4度）に固定する。マップごとの原点は持たない
- 道は実際の幅ではなく、道の種類ごとに決めたゲーム用の幅（`tools/osm_to_map.py` の `ROAD_WIDTH`）で描く。縮めても細い道が通れなくなるのを防ぐ
- 遠さは移動手段（「4. 移動手段」）で埋める
- 単調な住宅街だけを短くしたくなったら、県全体で一度だけ決めた「縮める強さの地図」に沿って滑らかに縮める。今は作らない

## 3. 区画の読み込み（済）

### 区画
- マップを 128m 四方の区画に分け、区画ごとに gzip した JSON にする。中身は地面・塞がっている所・建物の種類・建物・遮蔽物・路面の表示・標識・固定レール・ダッシュパッド
- 一覧の `index.json` に、範囲・出発地点・脱出地点・町名・区画と絵の番号を置く
- 全体マップ用に、1m を1ピクセルで描いた 512m 四方の絵を置く

### 距離ごとにやること
画面に映るのは 70m × 60m ほどなので、かなり遠くで出し入れする。読み込む距離と捨てる距離に差をつけて、境目を行き来しても出し入れを繰り返さないようにしている。

| やること | プレイヤーからの距離 |
|---|---|
| 読み込む | 640m 以内。今の速さで8秒進んだ先からも 640m 以内 |
| 敵を動かす | 384m 以内 |
| 描く | 256m 以内（320m より遠くなったら片付ける） |
| 捨てる | 900m より遠く |

- ファイルの取得・展開・格子のデコードは Web Worker でする。届いた区画は、近い順に1フレーム2個まで置く
- 出撃の前に、出発地点の周りを読み終えるまで待つ
- 地面の板とテクスチャは捨てずに次の区画へ使い回す
- 当たり判定の格子は 2048m 四方を、端と端がつながった形で持つ。持っている区画は捨てる距離の2倍と先読みの分まで広がるので、それより広くしている
- 敵と箱は、ランの seed と区画の番号から決める。数は区画の歩けるマスの数に比例させ、勢力の縄張りは町ごとに町名から決める。倒した敵や開けた箱は、捨てた区画のぶんも覚えておき、戻ってきたら再現する

残っていること：

- 行き先が先に分かる移動（長距離移動レール・長距離移動アイテム）は、使っている間に行き先を読み終える。今は出撃の前だけ
- 読み込みが間に合わなかった区画は、地面と当たり判定を先に出し、建物の部品は後から足す
- 建物のメッシュは区画ごとに作って捨てている。GC が目立ったら使い回すか、Web Worker で組み立てる
- 全体マップを県の単位で見るときは、もっと縮めた段階の絵を足す
- 描画の1フレームの重さは、ブラウザで長い距離を走って確かめる。今はヘッドレスの Chromium でしか見ていない

## 4. 移動手段

数値は仮。

| 手段 | 距離 | 動き | 置き方・手に入れ方 |
|---|---|---|---|
| 固定レール | 中距離（50〜240m）。乗り継げば長距離 | 端（乗り場）で E を押すと、反対の端まで秒速 20m で進む。進む間は撃てる。ダッシュで降りる | 変換のとき、幅 9m 以上の道の直線に置く |
| ダッシュパッド | 30m | 板の向きに沿って歩いて踏むと、歩いていた向きへ 30m を 0.9 秒で飛ぶ。飛ぶ間は撃てる。横切っても飛ばない | 変換のとき、幅 9m 未満の道（service を除く）の 60m 以上の直線に 40m おきに置く |
| 自転車 | — | C で乗り降りする。乗るのに 0.4〜0.6 秒止まり、降りるのに 0.3 秒。秒速 12〜13.5m。乗っている間は撃てず、回復・ダッシュ・投げ物・スキルも使えない。左クリックか撃たれると降りる | 持ち込む装備（靴と別の枠）。拠点でクラフトする（ママチャリ・ロードバイク） |
| スキル・アイテム | — | 長距離移動レール（アルティメット）、長距離移動アイテム | `docs/plans/skills.md` と `docs/plans/items.md` |
| 新幹線・飛行機 | 地方から地方 | カットインを見せている間に行き先を読み込む | 地方を2つ以上作ってから決める |

### 固定レール
- 上り下りが別の way になっている大通りは、2本の真ん中に1本だけ通す
- レールどうしが交わる所で切り、端がその近く（25m 以内）なら端をそこへ動かす。大通りどうしが交わる所にはいくつものレールの端が集まるので、乗り場で E を押すとカーソルの向きに一番近いレールに乗る
- 秋葉原から東京駅までで 192 本・合計 23km。乗り継ぐと、出発した所から 1060m 離れた所まで 63 秒で行ける（`npm run smoke`）
- 全体マップとミニマップの絵にも描く

### パートナー
- プレイヤーが自転車に乗ると、ついて歩いているパートナーも乗る。撃ち合いを始めたら降りる
- 固定レールとダッシュパッドはプレイヤーだけが使う。離されたパートナーは、プレイヤーの速さの 1.1 倍（上限 24m/s）まで速く走って戻る
- 撃ち合っていないパートナーが 80m より離れたら、プレイヤーの後ろ（進んでいる向きの反対）の、プレイヤーまで歩いて行ける所へ移す。遠い所（34m）から試す

### 読み込み
- 区画の先読みは今の速さで決まるので、自転車や固定レールで速く進めば、そのぶん遠くまで読む。12m/s でマップ全体をジグザグに走っても、周りの区画が間に合わなかったことはない（`npm run smoke`）
- 固定レールは始点のある区画のファイルに入れ、区画と一緒に置いて外す。レールは 240m 以下なので、乗っている間に始点の区画が捨てられることはない

### 敵
- 敵は固定レール・ダッシュパッド・自転車を使わない。使わせるかは、敵の強さの調整を決めるときに決める

## 5. 範囲

`tools/osm-raw/kanto-261031.osm.pbf` から切り出す。秋葉原から神田を通って東京駅まで入れてある。座標は pbf の駅と町名の点から取った。

| 段階 | 緯度 | 経度 | 縮める前の広さ | 入る所 |
|---|---|---|---|---|
| 電気街 | 35.6960〜35.7050 | 139.7670〜139.7800 | 約 1.2km × 1.0km | 外神田1〜6丁目、末広町駅、中央通り、佐久間町、台東1丁目 |
| 東京駅まで（今） | 35.6770〜35.7050 | 139.7630〜139.7800 | 約 1.5km × 3.1km | 神田駅、大手町、日本橋、東京駅 |

その先は、移動手段がひととおりできてから区の単位で一度に広げ、さらに市や県の単位まで広げる。

- 今は範囲を変えるとマップ全体を変換し直す。東京駅までの範囲で、変換は1回 100 秒ほど。区の単位まで広げる前に、範囲を足したときはその範囲の区画だけ作り直せるようにする。区画の境目の建物や道は、隣の区画のぶんも少し読んでから切る
- 容量の見当：23区を 0.8 倍で区画にすると約2.4万区画。東京駅までの範囲では 210 区画、1区画 平均 7.1KB・最大 11.8KB なので、約 170MB
- GitHub Pages はサイト全体で 1GB までなので、県の単位まで行くと置き場所を別に考える


## 決めること

- 縮める倍率（今は 0.8 倍）と、道の種類ごとのゲーム用の幅（今の `ROAD_WIDTH` は、縮める前の試作で決めた値）
- 脱出の待ち時間（試作は呼んでから20秒）と、呼んだ音が届く距離（試作は 60m）
- キャンプを置ける距離（試作は 150m）と、1か所にするか複数持って出撃のときに選ぶか
- キャンプでできること（今はランの出発地点になるだけ。`docs/design.md` の「キャンプでできること」）
- 固定レールの速さ（秒速 20m）と、置く道の幅（9m 以上）。ダッシュパッドの間隔（40m）
- 自転車の速さと、乗り降りにかかる時間
- 県の単位まで広げたときのファイルの置き場所
