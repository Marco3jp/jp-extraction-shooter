# パートナーの計画

敵は3人組で来るのに、こちらは1人で戦っている。プレイヤーの動きに合わせて戦うパートナーを2体まで連れていけるようにする。最初は「AI ロボット」という仮の設定で、2体とも同じ作りにする。

## 動き

- プレイヤーの左後ろと右後ろ、4m ほど離れて付いてくる。走ればパートナーも走る
- プレイヤーが撃っている相手を優先して撃つ。プレイヤーが撃っていなければ、パートナーが見えている一番近い敵を撃つ
- プレイヤーが回復を始めたら、プレイヤーと敵の間に寄って撃ち返す
- 自分のシールドが割れたら遮蔽の裏で回復する（敵の「引いて巻く」と同じ）
- プレイヤーから 25m 以上離れたら、撃ち合いをやめて戻る
- 箱は開けない。拾い物の扱いは `docs/plans/items.md` で決める
- 脱出はプレイヤーと一緒にする。プレイヤーが脱出地点に入っていれば、パートナーがどこにいても脱出できる

### 強さ
敵1人より少し弱くする。プレイヤーが主役のまま、3対1 が 3対3 に近づく程度にとどめる。案として、敵の中距離型の武器で、ダメージ 70%・反応の遅さ 1.3 倍。

### 倒れたとき
- シールドとヘルスが 0 になると、その場で止まる。ランの中では消えない
- プレイヤーが近くで E を 4 秒押すと、ヘルス 50 で立ち上がる。撃たれると押し直し
- 止まったまま脱出すると、そのパートナーも一緒に戻る（パートナーそのものは失わない）

### 見え方
- パートナーが見ている敵は、プレイヤーが見ているのと同じ扱いで情報の段階を出す。センサーの延長として、パートナーは目の数を増やす役にもなる
- 体の色をプレイヤー寄りにし、頭の上に番号を出す
- HUD の左下に、2体のシールドとヘルスの棒を出す

## 作り

### 種類としての扱い
- `Actor.team` に `"partner"` を足す。勢力はプレイヤーと同じ `PLAYER_FACTION` にする。弾は同じ勢力に当たらない（`updateBullets`）ので、撃ち合いはそのまま成り立つ
- 敵の狙う相手の選び方（`src/sim/ai.ts` の `scan`）はプレイヤーを少し優先している（距離を 0.9 倍で見る）。パートナーもそのままにして、敵はプレイヤーを少し優先する
- `team === "enemy"` で敵だけを選んでいる所（`updateInfo`、`mapview.ts`、`hud.ts`、`renderer.ts`、`combat.ts` の倒した数）を、パートナーを数えないように見直す

### 動きの書き方
敵の状態遷移（`updateEnemy`）は巡回が中心なので、パートナーは `src/sim/partner.ts` に別に書く。撃つ・リロード・回復・遮蔽を探す・経路を引く処理は `ai.ts` から関数を出して共通で使う。

状態は「付いていく」「撃ち合う」「回復」「戻る」「止まっている」の5つ。

### 持ち物
- 弾は減らない（今の敵と同じ）
- シールドセルは自分で 2 個持って始める。足りなくなったときにプレイヤーから渡すかは `docs/plans/items.md` で決める

### 拠点の画面
- `Profile` に `partners: { enabled: boolean; weapon: WeaponType }[]`（2体分）を足す
- 装備の画面で、連れていくか、どの武器を持たせるかを選ぶ。武器のアタッチメントは最初は付けない
- パートナーの装備のクラフトは `docs/plans/items.md`

### 確かめ方
`npm run smoke` に足す。

- プレイヤー役のボット＋パートナー2体 対 敵の3人組 を 100 回回して、勝ち数と残った体力
- パートナーなし・1体・2体で比べる
- パートナーがプレイヤーから 25m 以上離れている時間の割合
- 1ティックの処理時間

## 作る順番

1. パートナーを1体出して、付いていくだけ
2. 撃ち合い（プレイヤーの狙う相手に合わせる）と回復
3. 倒れたときと、起こす操作
4. 2体にする。左右の位置取り
5. 見えている敵の共有、HUD
6. 拠点の画面

## 決めること

- 強さ（案は敵のダメージの 70%）
- 倒れたときに、時間で勝手に起きるか、プレイヤーが起こすか（案はプレイヤーが E 長押し）
- 遠くへ行かせる・待たせるといった指示を出せるようにするか。出すならキー（中クリックで指した所へ行かせる、など）
- パートナーは成長するか（`docs/design.md` の「パートナーの役割」）
- 役割を分けるか（戦闘・索敵・荷物持ち）。今は2体とも戦闘
