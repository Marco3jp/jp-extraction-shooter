# パートナー

敵は3人組で来るのに、こちらは1人で戦っている。プレイヤーの動きに合わせて戦うパートナーを2体まで連れていける。「AI ロボット」という仮の設定で、拠点でクラフトして作る。

定義は `src/data/partners.ts`、動きは `src/sim/partner.ts`。

## クラフト

数値は仮。

| レシピ | 作れる条件 | お金 | 素材 | できるもの |
|---|---|---|---|---|
| パートナー1（初期型） | なし | 1,200円 | 金属くず 12・電子部品 3 | シールド 100 |
| パートナー2（改良型） | パートナー1がいる | 3,500円 | 電子部品 6・精密部品 2 | シールド 125 |
| パートナー1を改良型にする | パートナー2がいる | 2,000円 | 電子部品 4・精密部品 1 | シールド 100 → 125 |

- 初期型と改良型の違いはシールドの上限だけ。武器・ダメージ・反応は同じ
- 作ったパートナーは負けても失わない
- 作った時点で「連れていく」になる。出撃準備の画面で1体ずつ切り替えられる。作っていないパートナーは選べない

## 動き

- プレイヤーの左後ろと右後ろ、4m 離れて付いてくる。付く位置の向きはプレイヤーの向きへ 1 秒に 1.5 rad ずつ寄せるので、マウスを振っても左右は入れ替わらない。付く位置が塞がっていたり壁の向こうだったりしたら、2m、それも駄目ならプレイヤーの位置を目指す
- 付く位置から 5m 離れたら走り、7m 離れたらプレイヤーが走るより 15% 速く走って追いつく
- プレイヤーが3秒以内に当てた相手が見えていれば、それを撃つ。見えていなければ、見えている一番近い敵を撃つ
- 撃ち合いの間も付く位置を離れず、そこで左右に動きながら撃つ。プレイヤーが回復している間は、プレイヤーから敵の方へ 3m 出て撃ち返す
- シールドが割れてヘルスが 60 を切ったら、遮蔽の裏へ走って回復する（敵の「引いて巻く」と同じ）。プレイヤーから 15m 以内に遮蔽が無ければその場で巻く。回復は自分で2回分持って始める
- プレイヤーから 25m 以上離れたら撃ち合いをやめて戻り、10m まで寄ったら元に戻る
- グレネードと炎は敵と同じく避ける
- 弾は減らない（敵と同じ）。撃ち合っていない間に、半分を切ったマガジンを込め直しておく
- 箱は開けない
- 脱出はプレイヤーと一緒にする。プレイヤーが脱出すれば、パートナーがどこにいても、倒れていても一緒に戻る

### 強さ
敵の中距離型と同じアサルトライフルを持ち、ダメージ 85%・反応の遅さ 1.15 倍（数値は仮）。シールドは初期型 100・改良型 125。

`npm run smoke` の結果（100 回ずつ）：

| 試したこと | 結果 |
|---|---|
| パートナー（初期型）1体 対 敵の中距離型1人（18m） | 勝ち 25/100 |
| パートナー（改良型）1体 対 敵の中距離型1人（18m） | 勝ち 35/100 |
| 初期型の数値を、シールド以外も敵と同じにしたとき | 勝ち 36/100 |
| プレイヤー役のボット＋パートナー0・1・2体 対 敵の3人組 | 勝ち 2・2・7/100 |

- 敵と同じ数値でも1対1で負け越すのは、プレイヤーの近くを離れないため
- 3人組との試験は、プレイヤー役が動かずに立って撃つだけなので、3〜4秒でプレイヤーが倒れて終わる。パートナーの強さを決める材料にはならない

### 倒れたとき
- シールドとヘルスが 0 になると、その場で横になって止まる。ランの中では消えず、ランも続く
- プレイヤーが 2.2m 以内で E を 4 秒押し続けると、ヘルス 50・シールド 0 で立ち上がる。押している間にプレイヤーが撃たれたら最初から

### 見え方
- パートナーが見ている敵（38m 以内で視線が通る）は、プレイヤーが見ているのと同じ段階で情報を出す
- 体の色はプレイヤーより明るい青。頭の上に番号を出し、倒れていたら「倒れている」と起こしている進み具合を出す
- HUD の左下（自分のシールドとヘルスの上）に、2体のシールドとヘルス、回復中・リロード・戻っている・倒れている、を出す
- ミニマップと全体マップに、いつも水色の点で出す

## 作り

- `Actor.team` は `"partner"`、勢力はプレイヤーと同じ `PLAYER_FACTION`。弾は同じ勢力に当たらない
- 敵の狙う相手の選び方（`scan`）はプレイヤーを少し優先している（距離を 0.9 倍で見る）。パートナーはそのままで、敵はプレイヤーを少し優先する
- 状態は「付いていく」「撃ち合う」「回復」「戻る」の4つ。倒れている間は `alive` が false で、`Actor.partner.reviveT` に起こしている秒数を持つ
- 経路を引く・遮蔽を探す・投げ物を避ける処理は `src/sim/ai.ts` のものを使う。敵に声をかける `alert` は、パートナーには狙う相手を覚えさせるだけ
- 武器は敵と同じく下限 1.5 秒で作り、ダメージと弾速は `Actor.mods` の修正で下げる。強化パーツを渡すと同じ仕組みで足す
- 敵と箱を置いた後にパートナーを出すので、連れていくかどうかで敵と箱の並びは変わらない
- 拠点：`Profile.partners` に2体分の `model`（0 は作っていない・1 は初期型・2 は改良型）と `enabled` を持つ（`PROFILE_VERSION` 4）。レシピは `src/data/recipes.ts` の `partner` の種類で、作れる条件は `craftBlocker` で見る
