# スキルの計画

スキル・パッシブ・アルティメットを1つずつ装備してランに出る。最初はどれでも自由に組み合わせられる。ユニークのセットと一般枠（`docs/design.md` の「ビルド」）は、この作りの上に後で載せる。

## 操作

- Q：スキル
- F：アルティメット
- リロードは R のまま

今は Q が武器の持ち替えに入っているので外し、持ち替えは 1 / 2・ホイールだけにする。

## 一覧

数値はすべて仮。クールダウンはスキル 15〜30 秒、アルティメット 60〜120 秒の範囲で置く。

### スキルとパッシブ

| 寄せ方 | スキル（Q） | パッシブ |
|---|---|---|
| 守り | シールド追加：シールドの上に 50 の追加シールドを張る。10 秒で消える。クールダウン 25 秒 | キルでシールド回復：倒すとシールドが 50 回復する |
| 移動 | 加速：8 秒間、移動速度 +30%。クールダウン 20 秒 | ダッシュ2回：ダッシュを2回まで溜められる。1回分は 5 秒で戻る |
| 奇襲 | 横滑りダッシュ：0.6 秒かけて 9m 進む。進む間に A / D で左右に曲がれる。撃てる。クールダウン 18 秒 | 巻き検知：40m 以内で回復している敵を、半径 6m の円で示す。円の中心は敵の位置からずらし、1 秒ごとに置き直す。壁越しにも出る。体力は出さない |
| 攻撃 | 速射：8 秒間、連射速度 +25%・リロード時間 −40%。クールダウン 25 秒 | 弾の威力：1発のダメージ +6% |

### アルティメット（F）

| 名前 | 動き | クールダウン |
|---|---|---|
| 遮蔽物 | カーソルの位置に、長さ 4m の壁を向きをそろえて立てる。弾を止め、耐久 400 で壊れる。30 秒で消える | 90 秒 |
| 広域探知 | 80m 以内の敵を、壁越しに型と体力まで（情報の段階3）8 秒間見せる | 100 秒 |
| 長距離移動レール | 自分からカーソルの方向へ最大 80m のレールを敷き、その上を秒速 22m で進む。進む間は撃てる。レールは 20 秒残り、E で乗り直せる | 120 秒 |
| 弾倉なし | 12 秒間、カバンの弾を直接撃つ。リロードしない | 75 秒 |

## 作り

### 土台：ラン中のステータス修正
今は武器の性能を持ち込みのときに `computeWeapon` で1回だけ計算している。スキルとバフアイテム（`docs/plans/items.md`）は、ラン中に修正を足したり外したりするので、次を足す。

- `Actor` に `mods: { source: string; mods: Modifier[]; until: number | null }[]` を持たせる。`until` が null なら外すまで続く（パッシブ・バフアイテム）
- 武器の修正に加え、プレイヤーの項目（移動速度・シールドの上限・ダッシュの回数・弾の威力・キルで回復する量）も修正で書けるようにする
- `mods` が変わったら、アタッチメントの修正と合わせて武器の性能を計算し直す。`RunLoadout` にはアタッチメントの一覧も渡す
- 修正の積み上げ方は今の `applyModifiers` と同じ（加算を足してから (1 + 割合の合計) を掛ける）

理論 TTK の下限（1.5 秒）は、アタッチメントまでの性能にだけ掛ける。スキルとバフはその後に掛けるので、効いている間は 1.5 秒を下回ってよい。`npm run ttk` には、スキルとバフを全部掛けたときの TTK も出す。

### スキルの定義
`src/data/skills.ts` に、スキル・パッシブ・アルティメットを型付きの定数で書く。

- 効き目の種類：修正を一定時間足す／パッシブとして足し続ける／きっかけで起きる（倒したとき）／専用の処理（横滑りダッシュ・遮蔽物・レール・弾倉なし・探知）
- 専用の処理は `src/sim/skills.ts` に置き、`step` から呼ぶ
- 「倒したとき」は `applyDamage` の死亡の処理からイベントで呼ぶ

### 専用の処理の中身

| スキル | 書き換える所 |
|---|---|
| シールド追加 | `Actor` に `overshield` を足し、`applyDamage` でシールドより先に減らす。HUD のシールドの棒に色を変えて足す |
| ダッシュ2回 | `dashCd` を、溜まっている回数と次に溜まるまでの時間に分ける |
| 横滑りダッシュ | 今のダッシュの処理（`updatePlayer`）に、進む向きを入力で曲げる形を足す |
| 巻き検知 | 回復中（`Actor.heal`）の敵ごとに、ずらした円を `World` に持たせる。描画とミニマップで円を出す |
| 遮蔽物 | `map.solid` のセルを一時的に `Solid.cover` にし、消えたら元に戻す。耐久は壁ごとに持つ。置いたとき・消えたときに敵全員の経路を引き直す（テルミットの炎と同じ） |
| 広域探知 | `updateInfo` で、範囲内の敵の段階を一定時間 3 にする |
| 長距離移動レール | レールを線分として `World` に持たせる。乗っている間はダッシュと同じく移動速度を上書きする。建物に当たる所でレールを止める |
| 弾倉なし | `pullTrigger` で、効いている間は `mag` の代わりにカバンの弾を減らす |

### 拠点の画面
- `Profile.loadout` に `skill` `passive` `ult` を足す。`PROFILE_VERSION` を上げ、`normalizeProfile` で既定値を埋める
- 装備の画面に、3つの枠と一覧を出す。最初から全部選べる

### ラン中の HUD
- 画面の下に、スキルとアルティメットのアイコン、残りのクールダウン、効いている残り時間を出す
- パッシブは小さなアイコンだけ出す

### 敵
最初は敵にスキルを使わせない。使わせるかは、敵の強さの調整を決めるときに決める。

### 確かめ方
`npm run smoke` に、スキルごとに次を足す。

- シールド追加・キルでシールド回復：受けたダメージと残りのシールド
- 加速・ダッシュ2回・横滑りダッシュ・レール：一定時間で進んだ距離
- 速射・弾の威力：1対1 の勝ち数の変化
- 遮蔽物：置いた壁で弾が止まるか、敵が回り込むか、消えた後に元の格子に戻るか
- 巻き検知：円の中心が敵の位置と一致しないか

## 決めること

- アルティメットを、時間だけで溜めるか、ダメージ・キルでも溜めるか（案は時間とアルティメット加速のアイテムだけ）
- ラン開始時に、アルティメットが溜まった状態で始めるか
- ユニークのセットと一般枠の数、手に入れ方（`docs/design.md` の「センサーとビルド」）
