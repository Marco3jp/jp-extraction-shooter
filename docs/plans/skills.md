# スキル

スキル・パッシブ・アルティメットを1つずつ装備してランに出る。今はどれでも自由に組み合わせられる。ユニークのセットと一般枠（`docs/design.md` の「ビルド」）は、この作りの上に後で載せる。

定義は `src/data/skills.ts`、ラン中の処理は `src/sim/skills.ts`。ステータス修正の積み上げ方と理論 TTK の下限の掛け方は `docs/tech.md` の「スキル・パッシブ・バフ」に書いている。

## 操作

- Q：スキル
- F：アルティメット。遮蔽物とレールは、カーソルの位置・向きに出す
- E：レールに乗り直す
- 武器の持ち替えは 1 / 2・ホイール

## 一覧

数値はすべて仮。クールダウンはスキル 15〜30 秒、アルティメット 60〜120 秒の範囲で置く。クールダウンは使った時点から数える。

### スキルとパッシブ

| 寄せ方 | スキル（Q） | パッシブ |
|---|---|---|
| 守り | シールド追加：シールドの上に 50 の追加シールドを張る。10 秒で消える。クールダウン 25 秒 | キルでシールド回復：倒すとシールドが 50 回復する |
| 移動 | 加速：8 秒間、移動速度 +30%。クールダウン 20 秒 | ダッシュ2回：ダッシュを2回まで溜められる。1回分は 5 秒で戻る |
| 奇襲 | 横滑りダッシュ：0.6 秒かけて 9m 進む。進む間は移動キーの向きへ曲がれる（1 秒に 150 度まで）。撃てる。クールダウン 18 秒 | 巻き検知：40m 以内で回復している敵を、半径 6m の円で示す。円の中心は敵の位置から 1.5〜3m ずらし、1 秒ごとに置き直す。壁越しにも出る。体力は出さない |
| 攻撃 | 速射：8 秒間、連射速度 +25%・リロード時間 −40%。クールダウン 25 秒 | 弾の威力：1発のダメージ +6% |

### アルティメット（F）

| 名前 | 動き | クールダウン |
|---|---|---|
| 遮蔽物 | カーソルの位置（最大 25m 先）に、狙った向きと直角に、マス目に沿って長さ 4m の壁を立てる。人がいるマスは飛ばす。弾を止め、耐久 400 で壊れる。30 秒で消える | 90 秒 |
| 広域探知 | 使った時点で 80m 以内にいる敵を、壁越しに型と体力まで（情報の段階3）8 秒間見せる | 100 秒 |
| 長距離移動レール | 自分からカーソルの方向へ最大 80m のレールを敷き、その上を秒速 22m で進む。建物の手前で止まる。進む間は撃てる。ダッシュで降りる。レールは 20 秒残り、E で遠いほうの端へ向かって乗り直せる | 120 秒 |
| 弾倉なし | 12 秒間、カバンの弾を直接撃つ。リロードしない | 75 秒 |

## 作り

| スキル | 書き換えている所 |
|---|---|
| シールド追加 | `Actor.overshield` を `applyDamage` でシールドより先に減らす。HUD ではシールドの棒の右に黄色で足す |
| ダッシュ2回 | `Actor.dashCharges`（溜まっている回数）と `dashCd`（次の1回が溜まるまで）に分けている |
| 横滑りダッシュ | ダッシュと同じ処理で、`dashSteer` のときだけ進む向きを移動キーへ曲げる |
| 巻き検知 | ずらした円を `World.healMarks` に持つ。描画では建物に隠れないように描き、ミニマップにも出す |
| 遮蔽物 | `World.barriers` に、書き換えたマスと耐久を持つ。弾が当たったマスがどの壁かを見て耐久を減らす。建物の向こうに立てても見えるように、隠れた所は薄く重ねて描く |
| 広域探知 | 敵ごとに `revealUntil` を持たせ、`updateInfo` でその時刻まで段階を 3 にする |
| 長距離移動レール | レールを線分として `World.rails` に持つ。乗っている間は `Actor.ride` を見て速度を上書きする。押されてレールから 1.2m 離れたら降りる |
| 弾倉なし | `pullTrigger` で、効いている間は `mag` の代わりにカバンの弾を減らす。リロードは始めない |

- 拠点：`Profile.loadout` に `skill` `passive` `ult` を持つ（`PROFILE_VERSION` 2）。知らない名前が入っていたら既定値に戻す。出撃準備の画面の下に3つの枠を出す
- HUD：武器の上に、スキルとアルティメットのアイコン・残りのクールダウン・効いている残り時間を出す。パッシブは小さなアイコンだけ
- 敵：スキルを使わない。使わせるかは、敵の強さの調整を決めるときに決める

## 決めること

- アルティメットを、時間だけで溜めるか、ダメージ・キルでも溜めるか（今は時間だけ。アルティメット加速のアイテムを足す案がある）
- ラン開始時に、アルティメットが溜まった状態で始めるか（今は溜まっていない状態で始める。`ULT_START_READY`）
- ユニークのセットと一般枠の数、手に入れ方（`docs/design.md` の「センサーとビルド」）
