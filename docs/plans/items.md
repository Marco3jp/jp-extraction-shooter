# アイテムの計画

ラン中に拾うものに、アルティメット加速・バフアイテム・蘇生アイテム・長距離移動アイテムを足す。持ち帰りの仕組みに、死んでも持ち帰れる枠（特殊カバン）を足す。パートナーの装備とパートナーへの受け渡しもここで扱う。

バフアイテム（画面での呼び名は「強化パーツ」）と、強化パーツの受け渡しはできている。

## ラン中に拾うもの

| 種類 | 効き目 | 出やすさ | 持ち帰り |
|---|---|---|---|
| アルティメット加速 | 使うと（2 秒）アルティメットのクールダウンが 40 秒縮む。カバンに入る。1枠に2個 | レア | しない |
| バフアイテム | 拾った時点からラン中ずっと効く。カバンの枠は使わない | レア〜エピック。マップ全体で1ランに 6 個ほど | しない |
| 蘇生アイテム | 死んだときに自動で使い、その場でヘルス 50 で立ち上がる | レジェンダリー。ラン1回に1個出るかどうか | できる |
| 長距離移動アイテム | 使うと（3 秒）、全体マップで選んだ脱出地点かキャンプへ移る | レジェンダリー | しない |

### バフアイテム（強化パーツ）
薬のような一時的なものではなく、アタッチメントやシールドの類で、そのランの間は装備が1つ増えたのと同じになる。負の効き目は付けない。定義は `src/data/buffs.ts`。

| 名前（仮） | 効き目 | 珍しさ | パートナーに効くか |
|---|---|---|---|
| シールドコア | シールドの上限 +25 | エピック | 効く |
| 拡張マガジンキット | マガジン量 +15% | レア | 効く |
| スタビライザー | 撃ち続けたときのブレ −15% | レア | 効く |
| クイックローダー | リロード時間 −15% | レア | 効く |
| 軽量フレーム | 移動速度 +4% | レア | 効く |
| 冷却ユニット | スキルのクールダウン −15% | エピック | 効かない |
| 予備バッテリー | ダッシュのクールダウン −20% | レア | 効かない |

- 箱と地面に出る。出やすさは1種類あたりレア 0.14・エピック 0.08（`BUFF_WEIGHT`。シールドセルは 16）
- 拾うとカバンに入らず、その場で効く。同じ種類は1個までしか効かない
- 同じ種類の2個目は、それが効くパートナーがいれば予備として持つ（カバンの枠は使わない）。いなければ拾えずに残る
- 持ち物の画面に、カバンの下に効いている強化パーツと予備を出す
- 効き目はスキルと同じく `Actor.mods` の修正で足す（`docs/tech.md` の「スキル・パッシブ・バフ」）。スキルとダッシュのクールダウンは、`ActorStat` の `skillCd` `dashCd`（基礎値 1 の倍率）で縮める

### 蘇生アイテム
- 拠点の保管庫に持てる。持ち込む装備の枠に1個だけ入れられる
- ラン中に拾った分は、カバンに入る。死んだときは、持ち込んだ分より先に拾った分を使う
- 立ち上がった直後の 2 秒はダメージを受けない
- 脱出すれば拾った分を持ち帰れる。死んで使わなかった分（2個目以降）は失う

### 長距離移動アイテム
- 移る先は、マップにある脱出地点と自分のキャンプ
- 使っている 3 秒の間に撃たれると止まる。アイテムは減らない

## 死んでも持ち帰れる枠

- 特殊カバンを拠点でクラフトすると、カバンとは別に死んでも持ち帰れる枠が付く。段階で 1・2・3 枠
- 枠には、素材・蘇生アイテムなど、持ち帰れるものの山を1つずつ入れられる。お金は入れられない
- 死んだとき（`applyRunResult`）、この枠の中身だけは保管庫に入る
- 特殊カバンは靴と同じく持ち込む装備の枠を1つ使う

## パートナーへの受け渡し

- 予備の強化パーツは、パートナーの 4m 以内で持ち物の画面を開くと「1に渡す」「2に渡す」で渡せる。近くにいるパートナーの強化パーツも並べて出す。渡したものはそのパートナーにだけ効き、ランが終われば消える
- まだ作っていないもの：シールドセル・ヘルス小・ヘルス大の受け渡し。パートナーは今、自分で持って始める2回分だけ巻き、無くなったら巻かずに戦う
- パートナーが箱を漁るかは、受け渡しを入れて遊んでから決める。漁らせる場合、プレイヤーが開けた箱の中身から回復アイテムだけを取る形にする

## パートナーの装備

- 拠点でクラフトする。パートナーごとに、武器のアタッチメントの枠（プレイヤーと同じ4か所）と、防具の枠を持つ
- アタッチメントはプレイヤーの持っている分から付ける（プレイヤーの武器に付けていない余りだけ）
- 負けても装備は失わない。ラン中に渡したものは失う

## 作り

### アイテムの定義
- `src/data/items.ts` の `ItemCategory` に `"ult"` `"revive"` `"travel"` を足す（`"buff"` はある）。`LOOT_TABLE` に出やすさを足す
- アイテムのアイコンを `src/ui/icons.ts` に足す

### 保存
- `Profile` に `items: { revive: number }`、`secureBags: SecureBagId[]`、`loadout.secureBag` `loadout.revive` を足す。`PROFILE_VERSION` を上げ、`normalizeProfile` で埋める
- `RunResult` に、死んでも持ち帰れる枠の中身と、拾った蘇生アイテムの数を足す

### 確かめ方
`npm run smoke` に足す。

- 拾える物の量に、新しいアイテムが1ランで何個出るか（強化パーツは入っている）
- 蘇生アイテムを持たせたボットが倒れたとき、立ち上がるか
- 死んだときに、死んでも持ち帰れる枠の中身だけが残るか

## 作る順番

`docs/plans/skills.md` の「ラン中のステータス修正」ができてから始める。

1. バフアイテム（済）
2. アルティメット加速（アルティメットができてから）
3. 死んでも持ち帰れる枠と特殊カバン
4. 蘇生アイテム
5. 回復アイテムの受け渡しと、パートナーの装備（強化パーツの受け渡しは済）
6. 長距離移動アイテム

## 決めること

- バフアイテムの種類と数値、出やすさ（今は1ランに 6 個ほど）
- 同じ種類のバフアイテムを重ねて効かせるか（今は1個まで）
- 蘇生アイテムの効き目（案はその場で立ち上がる。`docs/design.md` の「ロストと持ち帰り」にある「持ち物を守る」と選ぶ）
- 長距離移動アイテムの効き目（案はマップの中の脱出地点かキャンプへ移る。「その場で脱出する」と選ぶ）
- 死んでも持ち帰れる枠の数（案は 1〜3 枠）と、入れられる物
- パートナーに箱を漁らせるか
