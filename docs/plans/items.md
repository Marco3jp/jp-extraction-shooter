# アイテムの計画

ラン中に拾うものに、アルティメット加速・バフアイテム・蘇生アイテム・長距離移動アイテムを足す。持ち帰りの仕組みに、死んでも持ち帰れる枠（特殊カバン）を足す。パートナーの装備とパートナーへの受け渡しもここで扱う。

まだ作っていないのは、回復アイテムの受け渡しとパートナーの装備だけ。

## ラン中に拾うもの

数値は仮。出やすさは `src/data/items.ts` の `LOOT_TABLE` の重み（シールドセルは 16）。

| 種類 | 効き目 | 出やすさ | 持ち帰り |
|---|---|---|---|
| アルティメット加速 | 7 キーで使うと（2 秒）アルティメットのクールダウンが 40 秒縮む。溜まっているときは使えない。カバンに入る。1枠に2個 | レア。重み 0.4 | しない |
| バフアイテム | 拾った時点からラン中ずっと効く。カバンの枠は使わない | レア 0.14・エピック 0.08 | しない |
| 蘇生アイテム | 死んだときに自動で使い、その場でヘルス 50 で立ち上がる | レジェンダリー。重み 0.08 | できる |
| 長距離移動アイテム | 8 キーで使うと（3 秒）、全体マップで選んだ 500m 以内の所へ飛んでいく | レジェンダリー。重み 0.08 | しない |

- 重みは、マップ全体の山がおよそ 900 だった頃に、蘇生アイテムが1ランに1個出るかどうかになるように決めた。今は出撃のときに読む 640m の内だけで山が 5,300 ほどあり、そこに蘇生アイテムと長距離移動アイテムが 4.7 個ずつ、アルティメット加速が 17.5 個、強化パーツが 45 個出る（`npm run smoke`）
- アルティメット加速と長距離移動アイテムは、回復アイテムと同じく時間をかけて使う。使っている間は遅くしか歩けず、撃つ・ダッシュ・X で止まる（`src/data/heals.ts` の `HEALS`）

### バフアイテム（強化パーツ）
薬のような一時的なものではなく、アタッチメントやシールドの類で、そのランの間は装備が1つ増えたのと同じになる。負の効き目は付けない。定義は `src/data/buffs.ts`。

| 名前（仮） | 効き目 | 珍しさ | パートナーに効くか |
|---|---|---|---|
| シールドコア | シールドの上限 +25 | エピック | 効く |
| 拡張マガジンキット | マガジン量 +15% | レア | 効く |
| スタビライザー | 撃ち続けたときのブレ −15% | レア | 効く |
| クイックローダー | リロード時間 −15% | レア | 効く |
| 軽量フレーム | 移動速度 +4% | レア | 効く |
| 冷却ユニット | スキルのクールダウン −15% | エピック | 効かない |
| 予備バッテリー | ダッシュのクールダウン −20% | レア | 効かない |

- 箱と地面に出る。出やすさは1種類あたりレア 0.14・エピック 0.08（`BUFF_WEIGHT`。シールドセルは 16）
- 拾うとカバンに入らず、その場で効く。同じ種類は1個までしか効かない
- 同じ種類の2個目は、それが効くパートナーがいれば予備として持つ（カバンの枠は使わない）。いなければ拾えずに残る
- 持ち物の画面に、カバンの下に効いている強化パーツと予備を出す
- 効き目はスキルと同じく `Actor.mods` の修正で足す（`docs/tech.md` の「スキル・パッシブ・バフ」）。スキルとダッシュのクールダウンは、`ActorStat` の `skillCd` `dashCd`（基礎値 1 の倍率）で縮める

### 蘇生アイテム
- 拠点の保管庫に持てる。出撃準備の画面で1個だけ持ち込める。持ち込んだ分を使ったら保管庫から減る
- ラン中に拾った分は、カバンに入る。死んだときは、持ち込んだ分より先に拾った分を使う。死んでも持ち帰れる枠に入れた分は使わない
- 立ち上がるとヘルス 50・シールド 0。直後の 2 秒はダメージを受けない（`SELF_REVIVE`）
- 脱出すれば拾った分を持ち帰れる。死んだときは、カバンに残っていた分を失う
- HUD の「蘇生」に、カバンの分と持ち込んだ分の合計を出す

### 長距離移動アイテム
Apex Legends の Evac Tower のように、マップの中の好きな所へ飛んでいく。

- 使っている 3 秒の間に撃たれると止まる。アイテムは減らない
- 使い終えると全体マップが開き、500m の円が出る。円の中の歩ける所をクリックすると飛び立ち、アイテムが1個減る。Esc でやめたら減らない。選んでいる間に撃たれてもやめる
- 1.2 秒かけて 12m の高さまで上がり、秒速 40m で進み、1.2 秒かけて降りる。500m なら 15 秒ほど
- 飛んでいる間は撃てず、回復・ダッシュ・スキルも使えない。撃たれはする。建物の上を通る
- パートナーは飛んでいる間は後ろへ移さず、降りてから 80m より離れていれば後ろへ移す
- 飛んでいる間は、行き先の周りの区画も読む。着いたときに行き先の区画がまだ届いていなければ、届くまで行き先の上で待つ
- 動きは `src/sim/evac.ts`、数値は `src/data/travel.ts` の `EVAC`

## 死んでも持ち帰れる枠

- 特殊カバン（小・中・大）を拠点でクラフトすると、カバンとは別に死んでも持ち帰れる枠が 1・2・3 枠付く。出撃準備の画面で、靴や自転車と同じく1つ選んで持ち込む
- 枠には素材と蘇生アイテムの山を入れられる（`SECURABLE`）。お金は入れられない
- ラン中に持ち物の画面で、カバンの山をクリックすると枠へ移し、枠の山をクリックするとカバンへ戻す
- 死んだとき（`applyRunResult`）、この枠の中身だけは保管庫に入る

## パートナーへの受け渡し

- 予備の強化パーツは、パートナーの 4m 以内で持ち物の画面を開くと「1に渡す」「2に渡す」で渡せる。近くにいるパートナーの強化パーツも並べて出す。渡したものはそのパートナーにだけ効き、ランが終われば消える
- まだ作っていないもの：シールドセル・ヘルス小・ヘルス大の受け渡し。パートナーは今、自分で持って始める2回分だけ巻き、無くなったら巻かずに戦う
- パートナーが箱を漁るかは、受け渡しを入れて遊んでから決める。漁らせる場合、プレイヤーが開けた箱の中身から回復アイテムだけを取る形にする

## パートナーの装備

- 拠点でクラフトする。パートナーごとに、武器のアタッチメントの枠（プレイヤーと同じ4か所）と、防具の枠を持つ
- アタッチメントはプレイヤーの持っている分から付ける（プレイヤーの武器に付けていない余りだけ）
- 負けても装備は失わない。ラン中に渡したものは失う

## 作り

- アイテムの種類は `src/data/items.ts` の `ItemCategory` の `"ult"` `"revive"` `"travel"`
- 保存：`Profile` に `items.revive`（保管庫の蘇生アイテム）、`secureBags`、`loadout.secureBag` `loadout.revive` を持つ（`PROFILE_VERSION` 5）
- ラン：`World.secure` が死んでも持ち帰れる枠、`World.carriedRevive` が持ち込んだ蘇生アイテムの残り
- 持ち帰り：`RunResult` にカバンと枠の中身（お金・素材・蘇生アイテム）と、持ち込んだ蘇生アイテムを使ったかを渡す
- `npm run smoke` の「ラン中に使うアイテム」で、出る数、アルティメット加速で縮む秒数、蘇生で立ち上がる回数、死んだときに枠の中身だけ残るか、長距離移動で行き先に降りるかを見る

## 作る順番

回復アイテムの受け渡しと、パートナーの装備（強化パーツの受け渡しは済）。パートナーの強さの調整と一緒に決める。

## 決めること

- 出やすさ。今の重みは山がおよそ 900 だった頃の見積もりで、1ランで実際に漁る量に合わせて決め直す（強化パーツも同じ）
- 同じ種類のバフアイテムを重ねて効かせるか（今は1個まで）
- 蘇生アイテムの強さ。パートナーがいないと、立ち上がってすぐまた倒れることがある
- 長距離移動アイテムの届く距離（500m）と、飛んでいる間に撃たれるか
- 死んでも持ち帰れる枠の数（1〜3 枠）と、入れられる物
- パートナーに箱を漁らせるか
