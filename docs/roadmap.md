# 拡張の計画

ランの外（拠点・保管庫・クラフト・装備の組み立て）を受け止める土台を先に作り、その上にアタッチメント → センサー → スキル → 敵の順で載せる。

| 段階 | 状態 | 中身 | 先に決めること（`design.md` の「決めること」） |
|---|---|---|---|
| 1. 土台 | 済 | ステータス修正の積み上げ、画面の流れ（拠点 → 出撃 → 結果）、保存、データの分割 | なし |
| 2. 持ち込みと持ち帰り | 仮の値で済 | 保管庫、装備の組み立て、クラフト、アタッチメント、5種の武器、防具・カバン・靴 | 死んだときの扱い、アタッチメントの箇所数、クラフトの段数と量 |
| 3. センサーと情報 | まだ | 設置型モジュール、無線の設置数、強化 | 開始時に見えるもの、強化の項目、使うときのコスト |
| 4. ビルド | スキル・パッシブ・アルティメット、ラン中のバフ（強化パーツ）、パートナー2体は仮の値で済（`docs/plans/skills.md` `items.md` `partners.md`）。パートナーの武器選び・装備・回復アイテムの受け渡しはまだ | スキル・パッシブ（ユニークのセット＋一般枠）、アルティメット、ラン中のバフ、パートナー | セットの数と手に入れ方、枠の数 |
| 5. 敵 | まだ | 敵の能力表、人間が使うドローン・ロボット、エリアの難易度 | 敵の強さの調整を何に結び付けるか |
| 6. 世界 | 地図の変換、建物の種類・路面の表示・町名、複数の脱出地点、キャンプ、区画の読み込み、0.8 倍で縮めた電気街（計画：`docs/plans/map.md`） | マップの追加、ダッシュパッドと乗り物、物語 | キャンプでできること、縮める倍率、物語の見せ方 |
| 段階の外：射撃場 | まだ | 拠点から入り、武器・アタッチメント・スキルを試せる場所 | 置く的の種類（動かない・動く・撃ち返す）、画面に出す数値（ダメージ・実際に倒すまでの時間など）、専用のマップにするか |

## 段階ごとの作り
### 1. 土台
- 武器・防具・プレイヤーの性能は、基礎値に修正（加算・乗算）を積み上げて計算する。アタッチメント・スキル・バフはすべてこの修正として書く
- 画面は「拠点」「ラン」「結果」を切り替える。拠点のメニューは Preact、ラン中の HUD は DOM を直接書き換える
- 保管庫・素材・装備・組み立ては IndexedDB に保存し、JSON で書き出し・読み込みできる

### 2. 持ち込みと持ち帰り
段階の外で、投げ物（グレネード・テルミット）とダッシュも入っている。

- 武器は種類ごとに1つ。アタッチメントの組み合わせで傾向を変える
- 武器ごとに弾薬が1種類ある（5種類）
- どの組み合わせでも理論 TTK が下限（プレイヤー0.75秒・敵1.5秒）を下回らないことを `npm run ttk` で全組み合わせ確認する

### 3. センサーと情報
見える情報の出どころを「範囲・出せる段階・壁を越えるか」を持った一覧にし、視線・ビーコン・設置モジュール・スキルを同じ形で扱う。

### 4. ビルド
- スキル・パッシブ・アルティメットを1つずつ装備する。今は最初から全部選べる。ユニークのセットと一般枠は、この上に載せる
- ラン中のスキルとバフは、ステータスの修正として足し外しする。理論 TTK の下限はアタッチメントまでの性能に掛け、スキルとバフはその後に掛ける

### 5. 敵
敵の強さの調整項目を「敵の能力表」に分け、エリアや装備で差し替える。`npm run smoke` で、決まった動きのボットとの1対1・1対3の勝率を出して効き目を測る。

### 3〜5 で共通
設置物（センサー・タレット）、ドローン、パートナーは、すでに入っている投げ物と同じく、人とは別の種類としてマップ上に置く。

### 6. 世界
- マップは OpenStreetMap から自動で変換する。全体を同じ倍率（0.8 倍）で縮め、128m 四方の区画ごとに読み込む（`docs/plans/map.md`）
- 地方から地方への移動（新幹線・飛行機）は、カットインの間に行き先を読み込む
- マップを増やすときは `tools/maps/` に設定を足し、`npm run extract-map` と `npm run map` を流す。範囲が地方のファイルの境目をまたぐときは、2つのファイルを `osmium merge` でまとめてから切り出す
